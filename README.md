# CEO en Control — Landing Page

Landing page del bootcamp virtual "CEO en Control" de Growth Institute (29–30 agosto 2026).

## Estructura

- `index.html` — contenido y copy de la página
- `css/styles.css` — estilos
- `js/script.js` — lógica de precios dinámicos (calcula la ventana de precio activa según la fecha real y actualiza los montos + countdown)

## Pendiente antes de publicar
